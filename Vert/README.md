# Dr. Shivika Veterinary Clinic Website

A premium, modern, and responsive website built for a veterinary clinic.

## Features

- **Responsive Design**: Mobile, tablet, and desktop friendly.
- **Dark/Light Mode**: User preference toggle for dark and light themes.
- **Glassmorphism & Gradients**: Premium UI/UX aesthetics.
- **Custom Animations**: Scroll reveal, counters, typing effects, and hover transitions.
- **Appointment Booking**: JavaScript form validation and animated success popup.
- **Sliders & Lightbox**: Interactive gallery and testimonial sections.

## Technologies Used

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript

## Structure

- `index.html`: Main page
- `css/`: Stylesheets (`style.css`, `responsive.css`, `animations.css`)
- `js/`: Scripts (`script.js`, `appointment.js`, `slider.js`)

## Running Locally

Simply open the `index.html` file in any modern web browser or use a local server like Live Server in VS Code.
