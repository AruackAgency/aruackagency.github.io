# Images Directory

Place your clinic and doctor images here.

## Recommended images:
- `doctor.jpg` — Main doctor portrait (400×500px recommended)
- `clinic-reception.jpg` — Reception area
- `clinic-consultation.jpg` — Consultation room
- `clinic-waiting.jpg` — Waiting area
- `clinic-equipment.jpg` — Medical equipment
- `og-image.jpg` — Open Graph social share image (1200×630px)
- `twitter-card.jpg` — Twitter card image (1200×628px)

## Tips:
- Optimize images for web (use WebP format for best performance)
- Keep images under 200KB each
- Use descriptive filenames for SEO
