# Icons Directory

Place custom icon files here (SVG, PNG, ICO).

## Recommended:
- `favicon.ico` — Browser tab icon (32×32px)
- `favicon-16.png` — 16×16 favicon
- `favicon-32.png` — 32×32 favicon
- `apple-touch-icon.png` — iOS home screen icon (180×180px)
- `android-chrome-192.png` — Android icon (192×192px)
- `android-chrome-512.png` — Android icon (512×512px)

## Tip: 
Use https://realfavicongenerator.net/ to generate all favicon sizes from a single image.
